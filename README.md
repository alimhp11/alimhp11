## 👨‍💻 About Me

Hey! I'm **Ali**, a developer from Iran and a university student. I focus on backend development, especially building APIs and practical tools with Python.

- 🐍 **Main stack:** Python, Django, Django REST Framework
- 🔐 **Backend work:** authentication, JWT, permissions/RBAC, API validation and filtering
- 💳 **Real-world logic:** wallet workflows, database transactions, row locking and idempotency
- 🤖 **Building:** Telegram bots, automation and SaaS-style products
- 🐳 **Workflow:** Git, Docker and Docker Compose
- 🌱 **Next on my roadmap:** Redis, background jobs, production deployment and deeper PostgreSQL practice

> I care about understanding the logic behind the code—not just making it run.
